# سجل المتجاوز — Lord of Mysteries TTRPG

تطبيق ويب مستقل يعمل محليًا من `index.html`، بدون خادم أو قاعدة بيانات خارجية.

## المصدر الحاكم
تم بناء محرك القواعد من ملف:
`كتيب لورد الغوامض الخاص بي الاعبين(1)`.

ملاحظة المصدر المهمة: الكتيب يقول إن مجموع السمات النهائي **45**، وليس 60. لذلك التطبيق يطبق 45.

## ما هو مطبق
- إنشاء الشخصية والهوية.
- توليد 3d3 لكل سمة + ضبط المجموع إلى 45 وحد أدنى 3.
- الإحصائيات التلقائية: الصحة، الروحانية، التحمل، الدفاعات، العقلانية، الهضم.
- Dice Engine حقيقي وتسجيل الرميات.
- النجاح الكبير 20 والفشل الكبير 1 في الاختبارات العادية.
- الحظ، حرق الحظ (واجهة البيانات قابلة للتوسعة).
- المهارات السبعة المستويات، المهارات المرتبطة، وأزمنة التعلم الثلاثة والتعلم الذاتي.
- المسار/التسلسل كسجلات قابلة للتحرير.
- الجرعات والمواد والترقية واختبار 1d20+20 ومؤثراته الأساسية.
- التمثيل والهضم والتمثيل الحاسم والهضم الطبيعي.
- العقلانية، فقدانها، استعادتها، حالات الجنون، وفقدان السيطرة.
- الجرعات المتكررة وفشل الترقية كبيانات قابلة للتسجيل.
- الدرع وتقليل الضرر ومتطلبات القوة.
- السمعة والأصول والعملات.
- القتال: المبادرة، جولة الغارة، موارد الإجراءات، الصد/التفادي، تحويل الإجراء، الهجوم المضاد/الصراع كواجهة DM.
- الممتلكات.
- العالم المادي/الروحي/النجمي/الغموض الخارجي كسجلات لعب.
- أسرار DM.
- سجل أحداث الشخصية.
- PLAYER / DM.
- حفظ تلقائي في localStorage + تصدير واستيراد JSON.

## حدود المصدر
الكتيب لا يحتوي على قاعدة بيانات كاملة لأسماء 22 مسارًا، جميع أسماء الجرعات ومكوناتها، قدرات كل تسلسل، أو كل NPC/كيان. لم أضع بيانات من الذاكرة أو من Wiki مكانها؛ هذه العناصر تُدار كسجلات DM قابلة للإضافة.

## التشغيل
افتح `index.html` مباشرة في متصفح حديث.

للاستخدام كاستضافة ثابتة: ارفع الملفات الثلاثة إلى GitHub Pages أو Netlify أو أي static host.
